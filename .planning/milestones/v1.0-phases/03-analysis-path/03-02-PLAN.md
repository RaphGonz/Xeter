```python
from dataclasses import dataclass, field
from abc import ABC, abstractmethod
from typing import Any
import numpy as np

@dataclass
class Flag:
    flag_type: str    # "wrong_tool" | "no_tool" | "excessive_tool" | "parsing_error" | "wrong_tool_args"
    score: float      # similarity score that triggered the flag
    detail: dict      # always includes "metric" key; wrong_tool_args always includes "low_confidence": True

@dataclass
class SpanData:
    span_id: str
    tenant_id: str
    trace_id: str
    agent_name: str
    agent_model: str
    tool_name: str | None
    tool_description: str | None
    tool_arguments: str | None     # raw JSON string
    tool_output: str | None
    prompt: str | None
    response: str | None
    available_tools: list[dict] | None  # parsed list, each dict has "name" and "description" keys

class BaseAnalyzer(ABC):
    def __init__(self, model, thresholds: dict[str, float]) -> None: ...
    def embed(self, text: str) -> np.ndarray: ...        # shape (384,)
    def compare(self, a: np.ndarray, b: np.ndarray) -> float: ...  # cosine similarity [-1, 1]
    def log_score(self, metric_name: str, score: float) -> None: ...
    def flush_scores(self) -> list[tuple[str, str, float]]: ...  # (analyzer_name, metric_name, score)
    @property
    @abstractmethod
    def name(self) -> str: ...
    @abstractmethod
    def analyze(self, span: SpanData) -> list[Flag]: ...
```

<!-- Tool embedding cache (from 03-CONTEXT.md locked decision) -->
```python
import hashlib, json

class ToolCallAnalyzer(BaseAnalyzer):
    def __init__(self, model, thresholds):
        super().__init__(model, thresholds)
        self._tool_embed_cache: dict[str, list[np.ndarray]] = {}

    def _get_tool_embeddings(self, available_tools: list[dict]) -> list[np.ndarray]:
        tools_json = json.dumps(available_tools, sort_keys=True)
        cache_key = hashlib.sha256(tools_json.encode()).hexdigest()
        if cache_key not in self._tool_embed_cache:
            self._tool_embed_cache[cache_key] = [
                self.embed(f"{t.get('name', '')} {t.get('description', '')}")
                for t in available_tools
            ]
        return self._tool_embed_cache[cache_key]
```

**Class structure (locked by CONTEXT.md — do not deviate):**
- One class, `ToolCallAnalyzer(BaseAnalyzer)`
- `__init__(self, model, thresholds)` — calls `super().__init__()`, initialises `self._tool_embed_cache: dict[str, list[np.ndarray]] = {}`
- `name` property returns `"tool_call"` (string constant — this is the analyzer_name in span_scores)
- `analyze(self, span: SpanData) -> list[Flag]` — calls all six `_check_*` methods, extends a flat list, returns it
- `_get_tool_embeddings(self, available_tools)` — cache pattern from CONTEXT.md (hash-keyed in-memory dict)
- `_check_wrong_tool(self, span) -> list[Flag]` — implements FLAG-04, FLAG-05, FLAG-11:
  - If span.tool_name is None: return []
  - Embed span.prompt
  - If span.available_tools is not None and len > 0: embed all tools via `_get_tool_embeddings()`; rank by similarity to prompt; the top-ranked tool's name is the expected tool. If span.tool_name != top-ranked tool name AND score below threshold → wrong_tool flag. Log score for "prompt_vs_tool_rank".
  - Also compute prompt vs tool_name directly (FLAG-04) and prompt vs tool_description directly (FLAG-05): log both scores. If either is below threshold AND available_tools ranking also disagrees → wrong_tool flag (combine signals).
  - Detail dict: `{"metric": "prompt_vs_tool_rank", "expected_tool": top_ranked_name, "actual_tool": span.tool_name, "score": score, "ranked_tools": [{"name": t, "score": s} for t, s in top_n]}`
- `_check_wrong_args(self, span) -> list[Flag]` — implements FLAG-12:
  - If span.tool_arguments is None or span.prompt is None: return []
  - Embed span.prompt; embed span.tool_arguments (treat as text)
  - Log score "prompt_vs_tool_args"
  - If score < self._thresholds["wrong_tool_args"]: return Flag("wrong_tool_args", score, {"metric": "prompt_vs_tool_args", "score": score, "low_confidence": True})
- `_check_no_tool(self, span) -> list[Flag]` — implements part of FLAG-08:
  - If span.tool_name is not None: return [] (tool was called, skip)
  - If span.prompt is None: return []
  - Embed span.prompt; embed a generic "use tool" reference string (e.g., "call a function tool")
  - Log score "prompt_expects_tool"
  - If score > self._thresholds["no_tool"]: return Flag("no_tool", score, {"metric": "prompt_expects_tool", "score": score}) — high similarity means prompt expected a tool that was NOT called
- `_check_excessive_tool(self, span) -> list[Flag]` — implements part of FLAG-08:
  - If span.tool_name is None: return [] (no tool was called, skip)
  - If span.prompt is None: return []
  - Embed span.prompt; embed span.tool_name
  - Log score "prompt_vs_tool_relevance"
  - If score < self._thresholds["excessive_tool"]: return Flag("excessive_tool", score, {"metric": "prompt_vs_tool_relevance", "score": score}) — low similarity means tool was called but prompt doesn't warrant it
- `_check_parsing_error(self, span) -> list[Flag]` — implements FLAG-07:
  - If span.prompt is None: return []
  - Embed f"{span.agent_model} {span.prompt}" (model_name + prompt concatenated)
  - If span.response is not None: embed span.response; compute similarity
  - Log score "model_prompt_vs_response"
  - If score < self._thresholds["parsing_error"]: return Flag("parsing_error", score, {"metric": "model_prompt_vs_response", "score": score})
  - If span.response is None: return [] (cannot detect parsing error without response)
- `_check_response_anomaly(self, span) -> list[Flag]` — implements FLAG-06:
  - If span.prompt is None or span.response is None: return []
  - Embed span.prompt → `prompt_vec`; embed span.response → `response_vec`
  - Compute `score = float(self.compare(prompt_vec, response_vec))` (plain prompt-vs-response similarity)
  - Call `self.log_score("prompt_vs_response", score)` BEFORE the threshold test
  - If score < self._thresholds["response_anomaly"]: return [Flag("response_anomaly", score, {"metric": "prompt_vs_response", "score": score})]
  - Otherwise return []

**Anti-patterns to avoid (from 03-RESEARCH.md):**
- NEVER hardcode a numeric threshold — always `self._thresholds["metric_name"]`
- ALWAYS call `self.log_score()` BEFORE the threshold comparison
- Use `model.similarity(a.reshape(1,-1), b.reshape(1,-1))` not manual dot product
- Use `_get_tool_embeddings()` cache — never re-embed the same tool list
