Add GET /spans/{id} to the existing spans.py router:

1. Define response models:
   - `FlagDetail(flag_type: str, score: float, detail: dict | None, created_at: str)`
   - `ScoreDetail(analyzer_name: str, metric_name: str, score: float)`
   - `SpanDetailResponse(span_id: str, trace_id: str, parent_span_id: str | None, agent_name: str, agent_model: str, tool_name: str | None, tool_description: str | None, tool_arguments: str | None, tool_output: str | None, time_begin: str, time_end: str, duration_ms: float | None, status: str, flags: list[FlagDetail], scores: list[ScoreDetail], prompt: str | None, response: str | None, raw_response: str | None)`

2. Handler logic:
   - Depends on verify_session_token for tenant_id
   - Step 1 (parallel via asyncio.gather):
     - Fetch span from ClickHouse: `WHERE tenant_id = %(tenant_id)s AND span_id = %(span_id)s`. Use `asyncio.to_thread`. Select ALL columns including prompt_ref, response_ref, raw_response_ref.
     - Fetch flags from PostgreSQL: `SELECT * FROM flags WHERE tenant_id = :tid AND span_id = :sid`
     - Fetch scores from PostgreSQL: `SELECT analyzer_name, metric_name, score FROM span_scores WHERE tenant_id = :tid AND span_id = :sid` (CRITICAL: tenant_id filter mandatory, no RLS)
   - Step 2: If span is None (no ClickHouse row, or tenant_id mismatch), return 404 with `{"error": "not_found", "message": "Span not found", "status": 404}`. Cross-tenant access also returns 404 (no info leakage).
   - Step 3 (sequential, needs _ref columns): Fetch S3 payloads using prompt_ref, response_ref, raw_response_ref from the ClickHouse span row. Use aioboto3 async S3 client. Wrap in `asyncio.wait_for(timeout=5.0)`. Fetch all three fields (can use asyncio.gather for the three S3 gets).
     - S3 env vars: `S3_ENDPOINT_URL`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `S3_BUCKET` (same vars as worker/analyser)
     - Each S3 object contains `{"value": "<text>"}` — extract the "value" field
   - Step 4 (error handling):
     - On `asyncio.TimeoutError`: raise HTTPException 504 with `{"error": "s3_timeout", "message": "S3 payload fetch timed out", "status": 504}`
     - On any other S3 exception: raise HTTPException 502 with `{"error": "s3_error", "message": "Failed to fetch span payloads", "status": 502}`
     - Per locked decision: return full error response, NOT partial data
   - Step 5: Merge and return SpanDetailResponse. Derive status same as list (flagged/clean/pending). Compute duration_ms from time_end - time_begin.
