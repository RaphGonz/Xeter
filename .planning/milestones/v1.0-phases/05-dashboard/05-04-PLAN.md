     - Similarity score as number (e.g., "0.85")
     - Detail JSON (if present): rendered as formatted key-value pairs or collapsible JSON block
     - "Request Diagnostic" button (shadcn Button):
       - Enabled only for flagged spans (disabled + grey for clean/pending)
       - On click: call api.diagnose(token, spanId, flags). Show response inline below button.
       - Loading state while request in flight.
       - Display the 501 placeholder response body as a grey info box.

  c. **Scores section** (shown when scores[] is not empty):
     - List of analyzer_name + metric_name + score (formatted as small table or definition list)

  d. **Span metadata section:**
     - Dense key-value display of ALL span fields: agent_name, agent_model, tool_name, tool_description, tool_arguments, tool_output, time_begin, time_end, duration_ms, parent_span_id
     - Use a definition-list style (label on left, value on right, alternating row background)
     - tool_arguments: if valid JSON string, render formatted; otherwise render as-is
