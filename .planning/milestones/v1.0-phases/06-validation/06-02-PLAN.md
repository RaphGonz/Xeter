**MAIN TASK: Create `xeter/scripts/load_test.py`** — an async load test using httpx.AsyncClient:

1. **Setup phase:**
   - Register 3-5 tenants via POST /register (unique names with UUID suffix)
   - Collect API keys from registration responses
   - Pre-generate all 30,000 span payloads (500 rps * 60s) before the timer starts (per anti-pattern guidance)
   - Each payload must include: agent_name, agent_model ("gpt-4o"), tool_name, tool_description, tool_arguments (JSON string), prompt, response, available_tools (list of tool dicts), trace_id (UUID), xeter_schema_version ("1.0")
   - Vary payload sizes: some with short prompts, some with longer multi-paragraph prompts

2. **Load phase:**
   - Use `httpx.AsyncClient` with `httpx.Limits(max_connections=200, max_keepalive_connections=50)` and timeout=10s
   - Target `http://localhost:4318/v1/spans`
   - Send at 500 rps using `asyncio.sleep(1/500)` between task spawns
   - Rotate API keys across tenants
   - Track per-request latency and status codes
   - Run for 60 seconds

3. **E2E latency probe** (runs AFTER load test, at normal load):
   - Emit one span via direct POST to the analyser with a known span_id
   - Poll `span_scores` table via psycopg2 (connect to `localhost:5432` with xeter/xeter_dev_password) until a row appears for that span_id
   - Record elapsed time from POST to first score row
   - Assert < 5 seconds (SC4 requirement)
   - Use 0.5s poll interval, 10s timeout

4. **ClickHouse parts check:**
   - Wait 10 seconds after load test for batcher to finish flushing (per Pitfall 6)
   - Query `system.parts WHERE table = 'spans' AND active = 1` via clickhouse-connect (host=localhost, port=8123, password=xeter_dev_password)
   - Report active parts count
   - Assert < 300 (Too Many Parts threshold)

5. **Results output:**
   - Print to stdout: total requests sent, success/error counts, p50/p95/p99 latencies, active parts count, e2e latency result
   - Return a dict with all results for the runner script to consume

6. **Cleanup:**
   - Do NOT delete the test tenants (they'll be cleaned up by reset.py if needed)

The script should be runnable standalone: `python -m xeter.scripts.load_test` or `python xeter/scripts/load_test.py`.

Add a `--duration` flag (default 60) and `--rps` flag (default 500) for flexibility during development.

**conftest.py:**
Create a `two_tenant_stack` pytest fixture (module-scoped) that:
1. Registers Tenant A via POST http://localhost:8000/register (unique name with UUID)
2. Registers Tenant B via POST http://localhost:8000/register (unique name with UUID)
3. Logs in as Tenant A via POST http://localhost:8000/login -> gets token_a
4. Logs in as Tenant B via POST http://localhost:8000/login -> gets token_b
5. Emits one span for Tenant A via POST http://localhost:4318/v1/spans (using Tenant A's API key) with a known span_id_a
6. Emits one span for Tenant B via POST http://localhost:4318/v1/spans (using Tenant B's API key) with a known span_id_b
7. Waits 3 seconds for ingestion to complete (batcher flush)
8. Returns (token_a, token_b, span_id_a, span_id_b)

Use `httpx.Client` (sync) since pytest fixtures work better with sync HTTP.

**test_isolation.py:**
Write the following tests, all using the `two_tenant_stack` fixture:

1. `test_spans_list_returns_only_own_tenant` — GET /spans with token_a, assert span_id_b NOT in response span_ids, assert span_id_a IS in response span_ids
2. `test_cross_tenant_span_detail_returns_404` — GET /spans/{span_id_b} with token_a, assert 404 (not forbidden, not found — per existing decision)
3. `test_spans_list_tenant_b_sees_only_own` — GET /spans with token_b, assert span_id_a NOT in response span_ids
4. `test_span_detail_includes_correct_tenant_id` — GET /spans/{span_id_a} with token_a, assert tenant_id in response matches Tenant A's tenant_id (per anti-pattern: must verify tenant_id field, not just span_id absence)
5. `test_span_scores_isolation` — This is the critical one: span_scores has NO RLS (documented CRITICAL in score_writer.py). GET /spans/{span_id_a} with token_a, verify the response includes scores.
