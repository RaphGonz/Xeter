# Milestone v1.6: Release

**Status:** ✅ SHIPPED 2026-05-31
**Phases:** 29–31
**Total Plans:** 7

## Overview

v1.6 is the public release milestone: apply a license, clean up dev artifacts, improve the diagnosticer prompt, and produce exhaustive documentation. The repo was made legally licensed (GPL-3.0 + Commons Clause), all Python source files received SPDX headers, the diagnosticer prompt was extracted from source code into a maintainable template file with structured reasoning guidance, and the README was overhauled into a comprehensive developer-facing document covering install, SDK, all 24 detection checks, calibration, pluggable LLM, and performance.

## Milestone Summary

**Key Decisions:**
- GPL-3.0 + Commons Clause licensing: prevents anyone reselling Xeter-as-a-service while keeping it open source
- `prompt.md` has no SPDX header — it is a template sent verbatim to the LLM; a header would appear as visible prompt text
- `db-init` init container reuses the presenter Dockerfile — no extra Dockerfile needed; one-shot pattern with `restart: no` gates all four app services on schema readiness
- Dev credentials shown in Quick Start per threat model (dev-only, explicitly labeled) — security review confirmed acceptable

**Issues Resolved:**
- Inline prompt string in `context_assembly.py` was not maintainable; extracted to `prompt.md` with structured reasoning guidance
- README was a stale placeholder; rewritten as comprehensive v1.6 public-facing documentation
- Repo root was cluttered with dead dev artifacts (`check_tier4.py`, `VALIDATION-REPORT.md`) and missing a LICENSE file
