    Section 6 — Calibration (D-S-01 item 6, DOCS-05):
    - Step-by-step workflow: (1) Reset tunable thresholds to defaults — run `python -m xeter.scripts.calibrate --reset`; (2) Add fixture spans by running your agent against test cases and letting Xeter ingest them; (3) Run calibration per flag type — `python -m xeter.scripts.calibrate --flag-type <type>` — this prints the F1-optimal threshold; (4) Apply the output threshold to docker-compose.yml by setting the corresponding `WORKER_THRESHOLD_<FLAG_TYPE_UPPER>` env var under the `worker` service, then restart the worker.
    - Note that only tunable flag types (those NOT in BINARY_FLAG_TYPES) support calibration; binary flags use detection logic with no threshold to tune.

    Section 7 — Pluggable LLM (D-S-01 item 7, DOCS-06):
    - Three providers: Anthropic (default), OpenAI, Ollama
    - Env vars: DIAGNOSTICER_PROVIDER (values: `anthropic`, `openai`, `ollama`), DIAGNOSTICER_MODEL (e.g., `claude-haiku-4-5`, `gpt-4o-mini`, `llama3.2`), ANTHROPIC_API_KEY, OPENAI_API_KEY, OLLAMA_BASE_URL
    - Ollama note: set DIAGNOSTICER_PROVIDER=ollama and OLLAMA_BASE_URL=http://localhost:11434 to use a local model; no API key required. The diagnosticer service must be able to reach the Ollama host — use `host.docker.internal` when running in Docker on macOS/Windows.
    - All three env vars are configured under the `diagnosticer` service in deploy/docker-compose.yml.

    Section 8 — Performance (D-S-01 item 8, DOCS-07 — per D-P-01 scope only):
    - Lever 1 — WORKER_TRACE_FLUSH_TIMEOUT_S (default: 30): seconds of inactivity before a trace is flushed for analysis. Lower value = faster analysis but less span context per trace. Higher value = richer multi-span context, higher latency to first flag. Set under the `worker` service in deploy/docker-compose.yml.
    - Lever 2 — Embedder model swap: EMBEDDER_URL points to the embedder service. The default sentence-transformers model is `all-MiniLM-L6-v2`. Swap the model in `services/embedder/Dockerfile` for a smaller/faster model (e.g., `paraphrase-MiniLM-L3-v2`) to reduce embedding latency at the cost of detection accuracy; swap for a larger model (e.g., `all-mpnet-base-v2`) for higher accuracy at the cost of throughput.
