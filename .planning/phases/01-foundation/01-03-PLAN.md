TDD cycle covers these behaviors (write test FIRST, then implementation):

**Guard behaviors (unit tests — no DB needed):**
- `require_tenant(None)` raises `MissingTenantError`
- `require_tenant("")` raises `MissingTenantError`
- `require_tenant("  ")` (whitespace) raises `MissingTenantError`
- `require_tenant("valid-uuid")` returns `"valid-uuid"` unchanged

**Repository guard behaviors (unit tests with mock session):**
- `TenantRepository.get_by_id(id, tenant_id=None)` raises `MissingTenantError` — no DB call made
- `UserRepository.get_by_email(email, tenant_id=None)` raises `MissingTenantError` — no DB call made
- `ApiKeyRepository.verify(key, tenant_id=None)` raises `MissingTenantError` — no DB call made

**API key generation (pure unit tests — no DB needed):**
- `generate_api_key()` returns a tuple `(plaintext, hash)` where plaintext starts with `"xtr_"`
- `generate_api_key()` two calls return different keys (randomness check)
- `verify_api_key(plaintext, hash)` returns `True` when hash matches
- `verify_api_key("wrong", hash)` returns `False`

Test cases for guard:
- input: None → raises MissingTenantError
- input: "" → raises MissingTenantError
- input: "   " → raises MissingTenantError
- input: "00000000-0000-0000-0000-000000000001" → returns the UUID string unchanged

**RED phase — write all tests first in `xeter/tests/dal/test_tenant_guard.py`:**

Tests are pure unit tests (no DB). Mock the SQLAlchemy session using `unittest.mock.AsyncMock`. Tests import `require_tenant`, `MissingTenantError` from `shared.dal.base`, and the three repository classes.

**GREEN phase — implement in this order:**

1. `xeter/shared/dal/base.py`:
   - `MissingTenantError(RuntimeError)` — custom exception
   - `require_tenant(tenant_id: str | None) -> str` — strips whitespace, raises if falsy, returns value

2. `xeter/shared/db/postgres.py`:
   - `get_async_engine()` — creates `create_async_engine` from `DATABASE_URL` env var
   - `get_async_session_factory()` — returns `async_sessionmaker`
   - `tenant_session(session: AsyncSession, tenant_id: str)` — async context manager:
     - Opens `session.begin()`
     - Executes `SET LOCAL app.current_tenant_id = :tid`
     - Yields session
     - Auto-commits on exit
   - Critical: Use `text("SET LOCAL app.current_tenant_id = :tid")` — never string interpolation
   - Critical: Never use autocommit mode on RLS-protected connections (SET LOCAL requires a transaction)

3. `xeter/shared/db/redis.py`:
   - `get_redis_client()` — returns a `redis.asyncio.Redis` client from `REDIS_URL` env var
   - Import: `redis.asyncio` (from `redis` package, which is `pip install redis`)
   - Phase 1 only needs the connection setup; actual queue operations are Phase 2

4. `xeter/shared/dal/tenants.py` — `TenantRepository(session: AsyncSession)`:
   - `async create(name: str) -> Tenant` — inserts, returns model (no tenant_id guard — tenant creation is bootstrap-level)
   - `async get_by_id(tenant_id: str) -> Tenant | None` — calls `require_tenant(tenant_id)`, then queries

5. `xeter/shared/dal/users.py` — `UserRepository(session: AsyncSession)`:
   - `async create(tenant_id: str, email: str, password_hash: str) -> User` — calls `require_tenant(tenant_id)`, inserts
   - `async get_by_email(email: str, tenant_id: str) -> User | None` — calls `require_tenant(tenant_id)`, queries

6. `xeter/shared/dal/api_keys.py`:
   - `generate_api_key() -> tuple[str, str]` — returns (plaintext with `xtr_` prefix, bcrypt hash via passlib)
   - `verify_api_key(plaintext: str, stored_hash: str) -> bool` — bcrypt verify via passlib
   - `ApiKeyRepository(session: AsyncSession)`:
     - `async create(tenant_id: str, key_hash: str) -> ApiKey` — calls `require_tenant(tenant_id)`, inserts
     - `async get_by_tenant(tenant_id: str) -> list[ApiKey]` — calls `require_tenant(tenant_id)`, queries

7. `xeter/tests/conftest.py`:
   - `mock_session` fixture — `AsyncMock` session for unit tests
   - No real DB connection needed for unit tests in this plan

**REFACTOR phase:** Extract any shared patterns, ensure all repository `__init__` methods accept `AsyncSession`, ensure consistent import paths (`from xeter.shared.dal.base import require_tenant`).
