Implement `router = APIRouter()` with `POST /v1/spans` following RESEARCH.md Pattern 2 exactly:

```python
@router.post("/v1/spans", status_code=200)
async def ingest_span(
    span: SpanPayload,
    tenant_id: str = Depends(verify_api_key_header),
    s3: S3Client = Depends(get_s3_client_dep),
    batcher: SpanBatcher = Depends(get_batcher_dep),
    redis: Redis = Depends(get_redis_dep),
) -> dict:
```

Execution order (strict — do not reorder):
1. Upload payloads to S3: `refs = await s3.upload_span_payloads(tenant_id, span.span_id, span.prompt, span.response, span.raw_response, span.available_tools_ref)`
   - On exception: `raise HTTPException(status_code=500, detail="payload storage failed")`
2. Build ClickHouse row as a list matching `SPAN_COLUMNS` order exactly
3. `await batcher.add(row)`
4. `await enqueue_span_id(redis, span.span_id)` — on exception: log error, raise HTTPException 500
5. Return `{"accepted": True}`

For dependency injection, use `Request.app.state` to get the batcher (set during lifespan):
```python
def get_batcher_dep(request: Request) -> SpanBatcher:
    return request.app.state.batcher

def get_redis_dep(request: Request) -> Redis:
    return request.app.state.redis

def get_s3_client_dep(request: Request) -> S3Client:
    return request.app.state.s3_client
```

**Step 3 — Rewrite `xeter/services/analyser/main.py`:**

Replace the stub with a full FastAPI app using lifespan:

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI
from xeter.services.analyser.batch import SpanBatcher, get_clickhouse_client
from xeter.services.analyser.s3 import get_s3_client
from xeter.shared.db.redis import get_redis_client
from xeter.services.analyser.ingest import router as ingest_router

@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup
    app.state.batcher = SpanBatcher(get_clickhouse_client())
    await app.state.batcher.start()
    app.state.redis = get_redis_client()
    app.state.s3_client = get_s3_client()
    yield
    # Shutdown
    await app.state.batcher.stop()
    await app.state.redis.aclose()

app = FastAPI(title="Xeter Analyser", version="0.2.0", lifespan=lifespan)
app.include_router(ingest_router)

@app.get("/healthz")
async def healthz() -> dict:
    return {"status": "ok"}
```
