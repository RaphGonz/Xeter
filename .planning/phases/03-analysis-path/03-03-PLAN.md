  <action>
Create `xeter/services/worker/span_fetcher.py`. This module fetches a span row from ClickHouse and resolves all S3 payload references into their text content. The returned SpanData is the contract the analyzer operates on.

**File-level docstring** explaining: fetches span by span_id from ClickHouse (full scan — span_id is not in the ORDER BY primary key; acceptable for Phase 3 volume); fetches S3 payloads for prompt, response, raw_response (for future use), and available_tools; uses boto3 (sync) not aioboto3.

**`get_s3_client()` factory function:**
- Reads `S3_ENDPOINT_URL`, `S3_ACCESS_KEY`, `S3_SECRET_KEY` from env (same names as analyser's s3.py)
- `S3_BUCKET` defaults to `"xeter-payloads"`
- Returns `boto3.client("s3", endpoint_url=..., aws_access_key_id=..., aws_secret_access_key=...)`

**`_fetch_s3_text(s3_client, bucket, key) -> str | None` helper:**
- If key is None or empty string: return None
- `obj = s3_client.get_object(Bucket=bucket, Key=key)`
- `wrapper = json.loads(obj["Body"].read())`  — unwrap outer `{"value": "..."}` envelope
- Return `wrapper["value"]`  — the original field string
- On `ClientError`: log warning and return None (do not crash the worker)

**`_decode_available_tools(tools_string: str | None) -> list[dict] | None` helper:**
- If tools_string is None: return None
- `tools = json.loads(tools_string)` — parse the inner JSON string to get list[dict]
- If result is not a list: log warning, return None
- Return tools
- Wrap in try/except json.JSONDecodeError: log warning, return None

**`fetch_span(span_id: str) -> SpanData` function:**
- Create ClickHouse client via `get_clickhouse_client()` (reuse factory from analyser batch.py — import it: `from xeter.services.analyser.batch import get_clickhouse_client`)
- Query: `SELECT span_id, trace_id, parent_span_id, tenant_id, agent_name, agent_model, tool_name, tool_description, tool_arguments, tool_output, prompt_ref, response_ref, raw_response_ref, available_tools_ref FROM spans WHERE span_id = %(span_id)s LIMIT 1`
- If no rows returned: raise `ValueError(f"span not found: {span_id}")`
- Map row to a dict using column names (clickhouse-connect returns rows as lists; use `result.column_names` and `result.first_row`)
- Create boto3 S3 client via `get_s3_client()`
- Fetch text payloads: `prompt = _fetch_s3_text(s3, bucket, row["prompt_ref"])`, same for response and raw_response
- Fetch and decode available_tools: `tools_raw = _fetch_s3_text(s3, bucket, row["available_tools_ref"]); available_tools = _decode_available_tools(tools_raw)`
- Construct and return SpanData with all fields populated (tool_arguments taken from ClickHouse column directly — it is stored inline as a JSON string)

**Environment variables:** `CLICKHOUSE_HOST`, `CLICKHOUSE_PORT`, `CLICKHOUSE_DATABASE`, `S3_ENDPOINT_URL`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `S3_BUCKET`

```python
def write_flags(
    span_id: str,
    tenant_id: str,
    trace_id: str,
    flags: list[Flag],

```

- Open transaction manually: `conn.autocommit = False`
- Execute `SET LOCAL app.current_tenant_id = %s` with tenant_id

- `conn.commit()` on success, `conn.rollback()` + re-raise on exception
- On exception: log error with span_id + flag types, re-raise
