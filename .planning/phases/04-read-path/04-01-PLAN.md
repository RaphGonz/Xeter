1. Create `xeter/services/presenter/routers/spans.py`:
   - Import verify_session_token from deps.py
   - Define Pydantic response models:
     - `FlagSummary(flag_type: str, score: float)`
     - `SpanListItem(span_id: str, trace_id: str, agent_name: str, agent_model: str, tool_name: str | None, time_begin: str, duration_ms: float | None, status: str, flags: list[FlagSummary])`
     - `SpanListResponse(spans: list[SpanListItem], next_cursor: str | None)`
   - Cursor encoding: `base64.urlsafe_b64encode(iso_timestamp.encode()).decode()` / decode inverse
   - `GET /spans` handler:
     - Parameters: `limit: int = Query(default=50, ge=1, le=100)`, `cursor: str | None = Query(default=None)`
     - Depends on verify_session_token for tenant_id
     - Step 1: Query ClickHouse via `asyncio.to_thread(client.query, ...)` with `WHERE tenant_id = %(tenant_id)s` (mandatory tenant isolation), `ORDER BY time_begin DESC`, `LIMIT %(limit)s`. If cursor provided, add `AND time_begin < %(cursor_ts)s`. Select: span_id, trace_id, agent_name, agent_model, tool_name, time_begin, time_end.
     - Step 2: Extract span_ids from result. Query PostgreSQL flags table: `SELECT * FROM flags WHERE tenant_id = :tid AND span_id IN :span_ids`. Also query span_scores table: `SELECT span_id, analyzer_name, metric_name, score FROM span_scores WHERE tenant_id = :tid AND span_id IN :span_ids`. CRITICAL: span_scores has NO RLS, so the WHERE tenant_id clause is the sole isolation mechanism.
     - Step 3: Merge — for each span, derive status: if flags exist -> "flagged", elif scores exist -> "clean", else -> "pending". Compute duration_ms from (time_end - time_begin). Attach FlagSummary list from flags query.
     - Step 4: Compute next_cursor from last span's time_begin (if result count == limit). Return SpanListResponse.
   - ClickHouse client: get from `request.app.state.ch_client` (set in lifespan).
