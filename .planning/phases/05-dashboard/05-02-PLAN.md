  <action>
1. **Remove the Phase 1 stub** — delete services/view/index.html and services/view/package.json (the serve-based stub).

2. **Scaffold Next.js 15** — run `npx create-next-app@latest . --typescript --tailwind --eslint --app --src-dir --import-alias "@/*"` from services/view/. Accept defaults. This creates the full Next.js scaffold.

3. **Install shadcn/ui** — run `npx shadcn@latest init` with defaults (New York style, zinc theme). Then install needed components: `npx shadcn@latest add button card input label dropdown-menu badge sheet tabs separator table skeleton`.

4. **Install runtime deps** — `npm install nuqs zustand date-fns`.

5. **Create next.config.ts** — configure rewrites to proxy /api/* to the Presenter:
```typescript
import type { NextConfig } from 'next'
const nextConfig: NextConfig = {
  async rewrites() {
    return [{ source: '/api/:path*', destination: `${process.env.PRESENTER_URL ?? 'http://presenter:8000'}/:path*` }]
  },
}
export default nextConfig
```

6. **Create src/lib/auth.ts** — Zustand store with sessionStorage persistence:
- `token: string | null` (guarded with typeof window !== 'undefined')
- `setToken(t: string)` — saves to sessionStorage('xeter_token') + Zustand
- `clearToken()` — removes from sessionStorage + Zustand

7. **Create src/lib/api.ts** — typed API client:
- `login(email, password)` → POST /api/login, returns { session_token }
- `listSpans(token, params)` → GET /api/spans with query params + Authorization header
- `getSpanDetail(token, spanId)` → GET /api/spans/{id} + Authorization header
- `diagnose(token, spanId, flags)` → POST /api/diagnose + Authorization header
All functions throw on non-OK response.

8. **Create src/providers.tsx** — wraps children in NuqsAdapter from nuqs/adapters/next/app.

9. **Update src/app/layout.tsx** — import Providers, wrap {children} in <Providers>.

10. **Create src/app/page.tsx** — client component that checks useAuthStore token: if set, redirect to /spans; otherwise redirect to /login.

11. **Rewrite services/view/Dockerfile** — replace the `serve` stub:
```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY services/view/package*.json ./
RUN npm install
COPY services/view/ .
EXPOSE 3000
CMD ["npm", "run", "dev"]
```

12. **Update deploy/docker-compose.yml** view service — update volumes to mount services/view/src for hot-reload:
```yaml
view:
  build:
    context: ..
    dockerfile: services/view/Dockerfile
  ports:
    - "3000:3000"
  volumes:
    - ../services/view/src:/app/src
    - ../services/view/public:/app/public
  environment:
    PRESENTER_URL: http://presenter:8000
  depends_on:
    presenter:
      condition: service_started
```
