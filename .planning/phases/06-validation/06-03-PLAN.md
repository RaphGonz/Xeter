  <name>Task 1: Validation runner script and report writer</name>
  <files>xeter/scripts/validate.py</files>
  <action>
Create `xeter/scripts/validate.py` — the single entry-point runner per user decision.

The script executes four validation steps IN SEQUENCE with continue-all mode (every step runs regardless of prior failures):

**Step 1: Calibration**
- Import and run calibrate.py's main function (or invoke as subprocess: `python xeter/scripts/calibrate.py`)
- Capture: selected threshold, precision, recall, six calibrated threshold values
- Pass/fail: precision >= 0.80
- On exception: catch, record as FAIL with error message, continue

**Step 2: Load Test**
- Import and run load_test.py's main function (or invoke as subprocess)
- Capture: total sent, success/error counts, p50/p95/p99 latencies, active parts count
- Pass/fail: zero errors AND p95 < 200ms AND active_parts < 300
- On exception: catch, record as FAIL with error message, continue

**Step 3: Cross-Tenant Isolation**
- Run via subprocess: `python -m pytest xeter/tests/validation/test_isolation.py -v --tb=short`
- Set env var VALIDATION_STACK=1 in the subprocess environment
- Pass/fail: pytest exit code 0
- On exception: catch, record as FAIL with error message, continue

**Step 4: E2E Latency**
- This is already measured in load_test.py's e2e probe. Extract the result from Step 2.
- If Step 2 failed, run a standalone e2e probe: POST one span to analyser, poll span_scores via psycopg2, measure elapsed.
- Pass/fail: e2e_latency < 5.0 seconds

**Report generation:**
Write `VALIDATION-REPORT.md` at project root with:

- Header: Validation Report, generated timestamp, overall PASS/FAIL
- Results table: Step | Status | Detail (one row per step)
- Calibrated Thresholds table: Key | Old Value | New Value
- Load Test Detail section: duration, total requests, success/errors, p50/p95/p99 latencies, ClickHouse active parts
- Notes section: any warnings (e.g., "wrong_tool_args excluded from P/R calculation per design")

The script should:
- Print progress to stdout as each step starts/completes
- Exit with code 0 if all steps pass, code 1 if any fail
- Be runnable standalone: `python xeter/scripts/validate.py`
- Accept `--skip-calibration` and `--skip-load-test` flags for partial runs during development
