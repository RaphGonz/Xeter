<context>
The algorithm is a merge of the user's pseudocode (per-argument, type/format/grounding)
with the existing code (ARGS-01 output error patterns). Since `available_tools` has no
schema (only name + description), type checks were replaced with key-name heuristics.

The key architectural insight that emerged during implementation: format checks and
grounding checks must be decoupled — format checks catch structural invalidity
(wrong email format) while grounding checks catch semantic mismatch (right format,
wrong value). Format-valid args should NOT be grounding-checked because representation
can differ (ISO "2025-03-05" vs natural language "March 5th").

The containment fix addresses the main false positive class: long arg values (SQL
queries, long strings) that CONTAIN the relevant NER entity but score low on
SequenceMatcher because the entity is a small fraction of the total character count.
</context>
