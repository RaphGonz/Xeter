**Patching strategy for DiagnosisRepository:**

Use `unittest.mock.patch` as context manager to patch at the module where it's USED:
```python
with patch("xeter.services.presenter.diagnosis_service.DiagnosisRepository") as MockRepo:
    mock_repo_instance = MagicMock()
    mock_repo_instance.get_latest_for_span = AsyncMock(return_value=_make_diagnosis())
    MockRepo.return_value = mock_repo_instance
    # ... make request ...
```

For tests where `get_latest_for_span` returns different values on consecutive calls (Test 7):

mock_repo_instance.get_latest_for_span = AsyncMock(side_effect=[None, _make_diagnosis()])

**Session mock for tenant_session compatibility:**
The `get_session` override must yield an `AsyncMock` that supports `begin()` as a context manager.
Use:
```python
def _make_session_mock():
    session = AsyncMock(spec=AsyncSession)
    session.begin = MagicMock(return_value=AsyncMock(__aenter__=AsyncMock(return_value=session), __aexit__=AsyncMock(return_value=False)))
    session.execute = AsyncMock(return_value=MagicMock(scalar_one_or_none=MagicMock(return_value=None)))
    return session

async def _session_override():
    yield _make_session_mock()
```

And inject: `app.dependency_overrides[get_session] = _session_override`
