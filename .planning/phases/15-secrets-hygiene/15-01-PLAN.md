<task type="auto">
  <name>Task 2: Create generate-secrets.sh with correct password reuse pattern</name>
  <files>generate-secrets.sh</files>
  <action>
Create `generate-secrets.sh` at the repository root. The script must:

1. Use `#!/usr/bin/env bash` shebang and `set -euo pipefail`
2. Guard against overwriting a git-tracked .env: `if git ls-files --error-unmatch .env 2>/dev/null; then echo "ERROR: .env is tracked by git. Run: git rm --cached .env" >&2; exit 1; fi`
3. Generate shared passwords ONCE into shell variables BEFORE the heredoc — this prevents DATABASE_URL and POSTGRES_URL from having different passwords:
   ```bash
   PG_PASS=$(openssl rand -hex 32)
   REDIS_PASS=$(openssl rand -hex 32)
   MINIO_PASS=$(openssl rand -hex 32)
   CH_PASS=$(openssl rand -hex 32)
   SECRET_KEY=$(openssl rand -hex 32)
   MINIO_USER=xeter
   ```
4. Write .env via `cat > .env <<EOF ... EOF` using the pre-generated variables. The .env must include ALL vars that docker-compose.yml currently references, plus new ones from OPS-05 (REDIS_PASSWORD) and OPS-03 (MINIO_ROOT_USER, MINIO_ROOT_PASSWORD):
   ```
   DATABASE_URL=postgresql+asyncpg://xeter:${PG_PASS}@localhost:5432/xeter
   POSTGRES_URL=postgresql://xeter:${PG_PASS}@localhost:5432/xeter
   POSTGRES_PASSWORD=${PG_PASS}
   CLICKHOUSE_HOST=localhost
   CLICKHOUSE_PORT=8123
   CLICKHOUSE_DB=default
   CLICKHOUSE_USER=default
   CLICKHOUSE_PASSWORD=${CH_PASS}
   REDIS_URL=redis://:${REDIS_PASS}@localhost:6379
   REDIS_PASSWORD=${REDIS_PASS}
   MINIO_ENDPOINT=http://localhost:9100
   MINIO_ROOT_USER=${MINIO_USER}
   MINIO_ROOT_PASSWORD=${MINIO_PASS}
   MINIO_ACCESS_KEY=${MINIO_USER}
   MINIO_SECRET_KEY=${MINIO_PASS}
   S3_ACCESS_KEY=${MINIO_USER}
   S3_SECRET_KEY=${MINIO_PASS}
   MINIO_BUCKET=xeter-payloads
   S3_BUCKET=xeter-payloads
   DEV_API_KEY=dev-api-key-local
   DEV_TENANT_NAME=dev-tenant
   DEV_USER_EMAIL=dev@example.com
   DEV_USER_PASSWORD=$(openssl rand -hex 16)
   SECRET_KEY=${SECRET_KEY}
   DIAGNOSTICER_PROVIDER=anthropic
   DIAGNOSTICER_MODEL=claude-sonnet-4-6
   ANTHROPIC_API_KEY=CHANGE_ME_BEFORE_DEPLOY
   OPENAI_API_KEY=CHANGE_ME_BEFORE_DEPLOY
   ```
5. Print a summary: `echo ".env written. Fill ANTHROPIC_API_KEY and OPENAI_API_KEY before starting services."`

Make the script executable: `chmod +x generate-secrets.sh`

CRITICAL PITFALL: Do NOT call `openssl rand` inline inside the heredoc for vars that appear in multiple places (PG_PASS, REDIS_PASS, MINIO_PASS). Each inline call produces a DIFFERENT value — causing connection failures. Generate these into shell variables before the heredoc and reference the variables.

Note: `DEV_USER_PASSWORD` is single-use so calling openssl rand inline there is fine.
