3. Add InternalApiKeyMiddleware after the ALGORITHM line, before the Dependencies section. Add the necessary imports at the top of the file (Request, JSONResponse, BaseHTTPMiddleware already importable from fastapi and starlette):
   ```python
   from fastapi import Request
   from fastapi.responses import JSONResponse
   from starlette.middleware.base import BaseHTTPMiddleware

   class InternalApiKeyMiddleware(BaseHTTPMiddleware):
       async def dispatch(self, request: Request, call_next):
           if request.url.path == "/healthz":
               return await call_next(request)
           key = request.headers.get("X-Internal-Api-Key")
           if key != INTERNAL_API_KEY:
               return JSONResponse(
                   status_code=401,
                   content={"error": "unauthorized", "message": "Invalid or missing internal API key"},
               )
           return await call_next(request)

   app.add_middleware(InternalApiKeyMiddleware)
   ```
