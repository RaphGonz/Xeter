Design notes for trace buffer:

**Buffer structure:**
```python
# In main(), module-level or local dict:
trace_buffer: dict[str, list[SpanData]] = {}         # trace_id -> list of SpanData
trace_last_seen: dict[str, float] = {}               # trace_id -> time.monotonic() of last span
```

**After each successful process_span() call in the BRPOP loop:**
1. Look up span.trace_id (fetched span is returned from process_span or re-fetched — see design below)
2. Append span to trace_buffer[trace_id]
3. Update trace_last_seen[trace_id] = time.monotonic()
4. Check ALL trace_ids in trace_last_seen: if elapsed > FLUSH_TIMEOUT_S → flush that trace

**Flush procedure:**
```python
def _flush_trace(trace_id, spans, tenant_id, trace_analyzer):
    flags = trace_analyzer.analyze(spans)
    if flags:
        write_flags(None, tenant_id, trace_id, flags)
    del trace_buffer[trace_id]
    del trace_last_seen[trace_id]
```

**Design constraint:** process_span() currently discards the SpanData after use. To accumulate spans in the buffer, the BRPOP loop needs access to the SpanData. Options:
- A) Return SpanData from process_span() (minimal change, clean interface)
- B) Add a separate fetch outside process_span()

Use option A — change process_span() to return the SpanData it fetched. This is a minimal interface extension; existing callers that ignore the return value continue to work unchanged.

**tenant_id for trace flush:** All spans in a trace share the same tenant_id. Use the tenant_id of the first span in the buffer (trace_buffer[trace_id][0].tenant_id).

def process_span(span_id: str, analyzers: list) -> SpanData:
    """...existing docstring, update Returns section:
    Returns:
        The SpanData fetched for this span_id, for use by the trace buffer.
    """
    span = fetch_span(span_id)
    all_flags: list = []
    all_scores: list = []
    for analyzer in analyzers:
        flags = analyzer.analyze(span)
        scores = analyzer.flush_scores()
        all_flags.extend(flags)
        all_scores.extend(scores)
    write_scores(span_id, span.tenant_id, all_scores)
    if all_flags:
        write_flags(span_id, span.tenant_id, span.trace_id, all_flags)
    return span

**6. In the BRPOP loop**, after the successful `process_span()` call (inside the `try` block, after `logger.info("worker: processed span_id=%s")`), add trace buffer logic:

```python
# Accumulate span in trace buffer
trace_buffer.setdefault(span.trace_id, []).append(span)
trace_last_seen[span.trace_id] = time.monotonic()

# Check all traces for flush timeout
now = time.monotonic()
ready_trace_ids = [
    tid for tid, last in trace_last_seen.items()
    if now - last >= WORKER_TRACE_FLUSH_TIMEOUT_S
]
for tid in ready_trace_ids:
    spans_for_trace = trace_buffer[tid]
    tenant_id_for_trace = spans_for_trace[0].tenant_id
    try:
        trace_flags = trace_analyzer.analyze(spans_for_trace)
        if trace_flags:
            write_flags(None, tenant_id_for_trace, tid, trace_flags)
        logger.info(
            "worker: flushed trace trace_id=%s spans=%d flags=%d",
            tid, len(spans_for_trace), len(trace_flags),
        )
    except Exception as exc:
        logger.error("worker: failed to flush trace trace_id=%s: %s", tid, exc)
    finally:
        trace_buffer.pop(tid, None)
        trace_last_seen.pop(tid, None)
```
