<objective>
Add a static FLAG_TYPE_TO_ANALYZER_CLASS registry to calibrate.py so that
evaluate_flag_type() routes each flag_type to the correct analyzer class via
dict lookup instead of a hardcoded ToolCallAnalyzer import. All seven existing
flag types continue to map to ToolCallAnalyzer — zero behavior change. Also add
a recall floor guard: any hill_climb result where best_recall < 0.10 prints a
human-readable error and calls sys.exit(1) before accepting the threshold.

Purpose: Phases 24-27 introduce new analyzer classes. Without the registry, adding
a new flag type requires modifying evaluate_flag_type() manually. The registry is
the extension point. The recall floor blocks degenerate P=1.0, R=0.0 convergence
from silently producing unusable thresholds.

Output: Updated calibrate.py and new xeter/tests/test_calibrate_routing.py.
</objective>
