From xeter/services/worker/base.py (Flag and SpanData dataclasses — already present):
- Flag(flag_type: str, score: float, detail: dict)  # detail always has "metric" key
- SpanData(span_id, tenant_id, trace_id, agent_name, agent_model, tool_name, tool_description,
           tool_arguments, tool_output, prompt, response, raw_response, available_tools,
           expected_output_schema=None, parent_span_id=None)
- BaseSpanAnalyzer(embedder, thresholds) — inherited constructor; subclasses set self._thresholds, self._scores
- log_score(metric_name, score) appends (analyzer_name, metric_name, score) to self._scores
- flush_scores() returns list[(analyzer_name, metric_name, score)] and clears the buffer

OutputSchemaAnalyzer contract (to be implemented in plan 24-02 — write tests against this):
- name property returns "output_schema"
- __init__(embedder, thresholds) — D-06: same signature as BaseSpanAnalyzer; embedder is unused by Phase 24 checks
- analyze(span: SpanData) -> list[Flag] — dispatches to 5 private _check_* methods
- _check_output_schema_violation(span)  — fires when expected_output_schema is set AND response fails json.loads (D-01 sub-case A only)
- _check_required_fields_missing(span)  — fires when jsonschema iter_errors() yields e.validator == "required"
- _check_output_truncated(span)         — fires when raw_response shows finish_reason=length (OpenAI) OR stop_reason=max_tokens (Anthropic) OR unclosed JSON delimiter in response/tool_arguments
- _check_type_coercion_error(span)      — fires when jsonschema iter_errors() yields e.validator == "type"
- _check_context_overflow(span)         — fires when tiktoken cl100k_base token count of span.prompt exceeds self._thresholds["context_overflow"]

Score logging contract (D-04, mandatory per base.py log_score docstring):
- Each of the 4 binary checks calls log_score(metric_name, 1.0) on fire, log_score(metric_name, 0.0) on clean (with metric_name == flag_type for the 4 binary checks)
- _check_context_overflow calls log_score("prompt_token_count", float(token_count)) BEFORE threshold comparison; the numeric score IS the calibration signal (no 0.0/1.0 binary)
- Early-exit guards (field is None → return [] before any check logic) do NOT call log_score — span did not participate

Flag.detail contract for the 5 checks:
- output_schema_violation: {"metric": "output_schema_violation"}
- required_fields_missing: {"metric": "required_fields_missing", "missing_fields": [str, ...]}
- output_truncated:        {"metric": "output_truncated"}
- type_coercion_error:     {"metric": "type_coercion_error", "type_errors": [str, ...]}
- context_overflow:        {"metric": "prompt_token_count", "token_count": int, "threshold": float}
