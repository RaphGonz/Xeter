# BLOCKING CONSTRAINTS — Read Before Anything Else

- [ ] CONSTRAINT: fixture-ordering — `group_spans_by_trace` preserves **file insertion order** within each trace group, NOT span_id numeric order. When extending fixtures, the labeled span must be the **last row** for its trace_id in the JSONL file, or the loop will evaluate a clean span instead of the anomalous one. This was discovered by seeing labeled spans at position 3 while the loop evaluated position 4.

- [ ] CONSTRAINT: calibration timeout — `step_repetition` loops indefinitely without a timeout. Always use `timeout 900 python -m xeter.scripts.calibrate --flag-type <X>` for every calibration command.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| fixture-ordering | Inserted new clean spans before labeled row, but another clean span existed AFTER the labeled row in the file — making labeled span end up at wrong group position | blocking | After any fixture edit, run the position-check script before calibrating |
| verbose-on-hill-climb | `--verbose` has no effect during hill_climb; only works with `--eval-only` | advisory | Always use `--eval-only --verbose` for diagnostics |

## Position-check script (run after any fixture edit)
```python
import json, re
from collections import OrderedDict
rows = [json.loads(l) for l in open('fixtures/labelled_spans.jsonl')]
groups = OrderedDict()
for r in rows:
    groups.setdefault(r.get('trace_id',''), []).append(r)
issues = []
for tid, spans in groups.items():
    atype = next((r['anomaly_type'] for r in spans if r.get('anomaly_type')), None)
    if not atype: continue
    sids = [r['span_id'] for r in spans]
    if not any(re.match(r'new-', s) for s in sids): continue
    labeled_pos = next(i for i,r in enumerate(spans) if r.get('anomaly_type'))
    n = len(spans)
    loop_start = {'history_loss':3,'conversation_reset':4,'context_propagation_failure':1}.get(atype,1)
    if labeled_pos not in range(loop_start, n):
        issues.append(f'FAIL {atype} trace {tid[:8]}: labeled@{labeled_pos}, evals={list(range(loop_start,n))}')
if issues:
    for i in issues: print(i)
else:
    print('All fixture traces OK')
```
