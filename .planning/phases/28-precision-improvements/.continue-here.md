## Critical Patterns Established This Session

| Pattern | Description |
|---------|-------------|
| Binary checks | `information_withholding` and `step_repetition` are now binary — no threshold, no log_score. Same pattern if other checks have meaningless thresholds. |
| Fixture co-labeling | Use `anomaly_types: ["typeA", "typeB"]` for spans that genuinely exhibit multiple anomaly types. calibrate.py already supports this via `any(...)` check. |
| Verification guard (prompt text) | `_check_information_withholding` skips span[i] when prompt contains verification keywords — uses `re.search(r'\b' + kw + r'\b', prompt_i)` (word-boundary) to avoid matching "confirmation". |
| Tool-relevance guard | `_check_wrong_args` skips arg evaluation when tool fit score < 0.15 — prevents wrong_tool_choice FPs from polluting wrong_tool_args. |
| step_repetition = exact match | Uses normalised token-sorted key equality, not fuzzy ratio. Termination loops have different args per span — exact match naturally avoids cross-contamination. |
